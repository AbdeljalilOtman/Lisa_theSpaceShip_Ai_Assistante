## 🐛 Troubleshooting

**Backend won't start?**
```powershell
cd backend
python -m venv venv
.\venv\Scripts\Activate.ps1
pip install -r requirements.txt
```

**Frontend won't start?**
```powershell
cd frontend
npm install
```

**Ollama not working?**
- App still works with fallback responses!
- Or reinstall: https://ollama.ai
